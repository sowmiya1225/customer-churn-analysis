# 📊 Customer Churn Analysis

## 📌 Project Overview

This project analyzes customer churn patterns using Python, SQL, and Power BI.

The objective is to identify customer characteristics and service-related factors associated with customer churn and present the findings through an interactive Power BI dashboard.

## 🎯 Objectives

- Analyze overall customer churn
- Identify churn patterns across contract types
- Analyze payment methods and internet services
- Compare monthly charges between churned and retained customers
- Analyze customer tenure and support calls
- Build an interactive Power BI dashboard
- Generate business-oriented insights from customer data

## 📊 Power BI Dashboard

The dashboard includes:

- Total Customers
- Churned Customers
- Churn Rate
- Customer Churn Distribution
- Churn by Contract Type
- Churn by Payment Method
- Churn by Internet Service
- Average Monthly Charges by Churn
- Average Support Calls by Churn
- Average Age by Churn
- Average Tenure by Churn
- Customer Churn by Gender

## 🔍 Key Findings

- Total customers analyzed: 1,200
- Churned customers: 319
- Overall churn rate: 26.58%
- Churned customers show higher average monthly charges.
- Churned customers have lower average tenure compared with retained customers.
- Churned customers also show higher average support calls.

## 💡 Business Insights

The analysis can help businesses:

- Identify customers with higher churn risk
- Understand customer service issues
- Analyze pricing-related churn patterns
- Improve customer retention strategies
- Identify customer segments requiring additional attention
